ABOUT

Software projects, maintained in the open.

SneppX is the organization behind a collection of software repositories. This website is the public directory for those projects and their documentation and contribution information.

What this site covers

The project directory links to repositories published under the SneppX organization. Developer pages collect technical references. Community pages explain how to report problems and propose changes.

Where to verify information

Repository source, issue trackers, release records, and project documentation are authoritative. This site organizes those resources; it does not replace them.

Project scope

Projects have different purposes, technologies, and release schedules. Each project page should describe only capabilities that can be confirmed from its source repository.
